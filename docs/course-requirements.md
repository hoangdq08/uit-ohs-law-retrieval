# ĐỀ TÀI ĐỒ ÁN MÔN HỌC MÁY HỌC

**Lựa chọn 1 tập dataset phù hợp cho ý tưởng của nhóm.**  
**Thực hiện các yêu cầu sau:**

---

## 1. Mục tiêu của đồ án
1. Hiểu và phân tích bộ dữ liệu.
2. Thực hiện các bước tiền xử lý dữ liệu (EDA, xử lý thiếu, chuẩn hóa, mã hóa…).
3. Áp dụng các thuật toán Machine Learning để dự đoán / phân loại / dò tìm ….
4. So sánh hiệu suất các mô hình để tìm mô hình tốt nhất.
5. Đưa ra nhận xét, phân tích và kết luận dựa trên kết quả thực nghiệm.

---

## 2. Mô tả bộ dữ liệu
- Bộ dữ liệu gồm bao nhiêu mẫu. Có bao nhiêu lớp? Số lượng mẫu trong mỗi lớp? Có mất cân bằng hay không? Được gán nhãn như thế nào?
- Tập dữ liệu có phân chia tập train / val / test hay không? Mỗi tập có bao nhiêu mẫu. Các tập train / val / test có mất cân bằng hay không?

---

## 3. Yêu cầu nội dung đồ án

### 3.1. Phân tích dữ liệu (EDA)
- Tùy vào loại dữ liệu sinh viên tìm hiểu cách phân tích dữ liệu cho phù hợp:
  - Dữ liệu là Tabular
  - Dữ liệu Ảnh
  - Dữ liệu video

---

### 3.2. Tiền xử lý dữ liệu
- Tìm hiểu cách tiền xử lý dữ liệu đối với dữ liệu của đồ án.

---

### 3.3. Mô hình Machine Learning
Sinh viên phải cài đặt **ít nhất 3 mô hình cơ bản để so sánh các kết quả.**  
**Lựa chọn mô hình cho kết quả tốt**

---

### 3.4. Đánh giá mô hình
Với từng mô hình tùy vào bài toán có thể có các cách đánh giá khác nhau, bên dưới là gợi ý một số metrics cơ bản để đánh giá mô hình:
- Accuracy
- Precision, Recall, F1-score
- Confusion matrix
- So sánh hiệu suất giữa các mô hình
- Nhận xét tại sao mô hình này tốt hơn mô hình kia?

---

### 3.5. Phân tích kết quả bài toán
**Cần trả lời câu hỏi:**
- Model nào tốt nhất?
- Chênh lệch nhau bao nhiêu?
- Phân tích các metrics (precision, recall, F1-score)
- Phân tích confusion Matrix: Model hay nhầm class nào?
- Phân tích lỗi: Ảnh mờ hay rõ, class có gần giống nhau có gây nhầm lẫn hay không?
- So sánh train vs validation để xem xét có overfitting hay underfitting hay không?
- Model nào phù hợp với dữ liệu?
- Những điều gì ảnh hưởng đến kết quả?
