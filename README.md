# uit-ohs-law-retrieval

UIT Machine Learning course project (**CS114.F31.CN2.TTNT, Máy học**, instructor: ThS. Cáp Phạm Đình Thăng): a Vietnamese NLP lookup system for the Law on Occupational Safety and Health (Luật An toàn, vệ sinh lao động 84/2015/QH13, consolidated text 14/VBHN-VPQH 2024).

Two-stage architecture:
1. **Classifier (core ML):** question -> regulation group (8 classes, Articles 1–62). TF-IDF (1,2)-gram + MultinomialNB / LogisticRegression / LinearSVC / RandomForest.
2. **Retrieval:** within the predicted group, rank Articles by cosine similarity.

Deliverables (report, slides, notebook) are in Vietnamese for the course. Team checklist: `docs/team-todo.md`.

## Data

- **Synthetic training set:** 1600 questions (8 classes × 40 seed questions × 5 styles), generated by an LLM (Claude) from the law text following `docs/labeling-guidelines.md`. Annotators pick the Article only; the class label is derived from it (`ARTICLE_TO_LABEL`). Checked by `scripts/validate_generated.py`.
- **Real test set:** 42 in-scope questions from chinhsachonline.chinhphu.vn (176 collected: 42 in-scope, 127 out-of-scope, 7 multi-intent), labeled by an LLM (GPT) from the Article cited in the official answer, then checked by one team member labeling blind (`scripts/blind_labeling.py`; the second sheet was AI-assisted and is scored as a second LLM, not a human). Used only for evaluation, never for training or model selection.

## Setup

`underthesea` needs Python 3.12 (not yet on 3.14):

```bash
uv venv --python 3.12
source .venv/bin/activate
uv pip install -r requirements.txt
python -m src.preprocess "Công nhân KHÔNG được trang bị đồ bảo hộ lao động thì sao?"
```

## Full rerun

```bash
python -m scripts.validate_generated          # check data/raw/gen/c0..c7.jsonl
python -m src.dataset                         # -> data/processed/ohs_questions.csv (split by seed)
python -m scripts.build_real_test             # data/raw/real_labeled.jsonl -> data/processed/real_test.csv
python -m scripts.build_notebook
jupyter nbconvert --to notebook --execute --inplace notebooks/uit_ohs_law_retrieval.ipynb --ExecutePreprocessor.timeout=1800
python -m scripts.build_report                # -> reports/BaoCao_DoAn_MayHoc.docx (overwrites manual edits)
python -m scripts.build_slides                # -> reports/Slide_BaoCao_DoAn.pptx (overwrites manual edits)
streamlit run app.py
```

To change a real-test label, edit only `data/raw/real_labeled.jsonl` (`decision` = `in_scope` / `out_of_scope` / `multi_intent`, plus `article_id` when in scope). Do not edit `real_test.csv` by hand. Then rerun from `build_real_test` down.

## Experiment rules

- `random_state=42` everywhere.
- The vectorizer is inside the sklearn Pipeline, so it is fit on training folds only; val/test are transform-only.
- Split by seed question (`seed_id`) so paraphrases of one question never land in both train and test.
- Model selection uses validation Macro-F1 only. The real test set is never used for tuning.
- Report numbers come from `reports/results.json` produced by the notebook run, not written by hand.
